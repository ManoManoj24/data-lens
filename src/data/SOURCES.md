# Sources — Annotated Bibliography

Public pages consulted while writing **original** Data Lens summaries. Citations use **title + URL**. No substantial verbatim copying from DAMA-DMBOK PDFs/books or other paywalled chapter text.

---

## Data lifecycle

1. **Introduction to the Data Lifecycle – UW–Madison**  
   https://data.wisc.edu/data-literacy/lifecycle/  
   *Teaching-oriented lifecycle stages (Plan, Create, Manage, Use, Share, Collect/Reuse, Destroy) and related literacy concepts. Primary public comparator for the “UW-style” track content.*

2. **The Data Lifecycle – Harvard University Information Security & Data Privacy**  
   https://privsec.harvard.edu/data-lifecycle  
   *Practical Plan → Create/Collect → Store → Use → Share → Archive/Destroy guidance with security and minimization emphasis.*

3. **NIST Research Data Framework (RDaF)**  
   https://www.nist.gov/programs-projects/research-data-framework-rdaf  
   *Official project page describing six stages: Envision, Plan, Generate/Acquire, Process/Analyze, Share/Use/Reuse, Preserve/Discard.*

4. **NIST RDaF Version 2.0 (Special Publication 1500-18r2)**  
   https://www.nist.gov/publications/nist-research-data-framework-rdaf-version-20  
   https://nvlpubs.nist.gov/nistpubs/SpecialPublications/NIST.SP.1500-18r2.pdf  
   *Authoritative stage naming and framework purpose for research data management.*

5. **USGS Data Lifecycle**  
   https://www.usgs.gov/data-management/data-lifecycle  
   *Plan, Acquire, Process, Analyze, Preserve, Publish/Share plus cross-cuts (Describe, Manage Quality, Backup & Secure).*

6. **USGS Science Data Lifecycle Model (Open-File Report 2013–1265)**  
   https://pubs.usgs.gov/of/2013/1265/  
   PDF: https://pubs.usgs.gov/of/2013/1265/pdf/of2013-1265.pdf  
   *Public USGS report defining the Science Data Lifecycle Model used in comparison modules.*  
   *Fetch note: `https://www1.usgs.gov/csas/training/dm-sdl/resources/science-data-lifecycle.pdf` timed out; content confirmed via pubs.usgs.gov HTML + PDF download.*

## FAIR, privacy principles, quality, MDM

12. **FAIR Guiding Principles – GO FAIR Foundation**  
    https://www.go-fair.org/fair-principles/  
    *Canonical Findable, Accessible, Interoperable, Reusable principles with sub-principles.*

13. **Art. 5 GDPR – Principles relating to processing of personal data – GDPR.eu**  
    https://gdpr.eu/article-5-how-to-process-personal-data/  
    *High-level personal-data processing principles (educational citation only; not legal advice).*

14. **What Are Data Quality Dimensions? – IBM**  
    https://www.ibm.com/think/topics/data-quality-dimensions  
    *Widely taught six dimensions: accuracy, completeness, consistency, timeliness, validity, uniqueness.*

15. **What is Master Data Management? – IBM**  
    https://www.ibm.com/think/topics/master-data-management  
    *Master vs reference vs other data types; golden records and MDM purpose.*

## Notes on intentional non-use

- **DAMA-DMBOK full PDFs / Technics Publications book chapters** were **not** used as copy sources for module prose. KA names and hub-and-spoke structure come from public overview pages listed above.
- **DCAM detailed capability text** is member-only; only the public overview page informed high-level mentions.
- **CMMI / data management maturity** is referenced at a high level in glossary/governance as a maturity-style companion idea; learners should consult official materials for full models.
- **ISO 8000** is named in the glossary at a high level only (common teaching association with data quality), without pasting standard text.
